## Headline

On every source found, the deck's $1.0M–$1.45M for three device paths sits below the reported median private cost of a single 510(k): $3.1M in the UCLA/BCG survey, whose scope is unconfirmed. FDA user fees alone are about $35K–$590K for the three devices, depending on the path mix. No public evidence quantifies the saving from a shared QMS.
